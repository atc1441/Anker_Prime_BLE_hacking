## Game data

`wad/DOOM1.WAD` is id Software's Doom 1.9 shareware IWAD. Shareware may be redistributed.
It is episode 1 only. It is not the registered game.

`data/DOOM.DAT` is E1M1 from that file, packed for this engine. `src/gen` was generated
from the same file and is linked into `DOOM.BIN`. The strings and tables inside the pack
that come from the engine stay GPL-2.0-or-later.

## Binaries

Anyone who distributes `DOOM.BIN` or `data/DOOM.DAT` built from this tree has to ship:

- the GPL text (`COPYING`)
- the MIT notice of the LCD values (`LICENSES/MIT.txt`), which `DOOM.BIN` contains
- the corresponding source of the same build (GPL section 3), which is this tree

The registered Doom IWAD and anything converted from it are not in this tree and must not
be added.
